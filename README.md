This project is a simple text filtering application written in C#.

## Features
- Takes input from the user
- Checks offensive words using a dictionary
- Censors them (!@?*)

## Usage
Run the program and enter a text.

## Example

Input:
hello you idiot

Output:
hello you !@?*

- C#
- .NET Console App
